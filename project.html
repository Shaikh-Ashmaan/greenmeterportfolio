Project

Green Meter App

An interactive Python dashboard that calculates a company's estimated CO2e emissions from fleet, facility, and subcontractor activity, then models a reduction scenario against it in real time.

Try the live app →
What it does

Activity data in, two numbers out

Ten inputs — car/truck/bus distance, forklift hours, cargo flight time, office lighting/heating/cooling/computing energy, and subcontractor estimates — are each multiplied by a fixed emissions factor and summed into a baseline. Three sliders (EV share, distance reduction, cargo load factor) recompute an optimized total against the same inputs, so a viewer can see the effect of a policy change instantly instead of re-running a spreadsheet.
